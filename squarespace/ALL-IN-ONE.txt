MY WELLNESS PHYSICIANS: ALL WEBSITE CODE IN ONE FILE
====================================================

Each block below is complete: it carries its own styling, so nothing needs
to go in Custom CSS or Code Injection.

For each page:
  1. In Squarespace, create the page (Blank page) and set its URL slug.
  2. Delete the "Empty Page" section. Add a blank section.
  3. Add Block -> Code (a Code block, not a Text block).
  4. Copy everything between the START and END lines for that page
     (not the START/END lines themselves) and paste it into the Code block.
     Turn off "Display Source" if you see it.
  5. Stretch the block to full width. Save.
  6. Page settings (gear icon) -> SEO: paste the title and description shown.

// Services carousel: previous/next buttons and a progress bar for a scroll-snap row.
// Without this script the row still scrolls sideways by touch, trackpad or keyboard.
document.querySelectorAll('[data-carousel]').forEach((carousel) => {
  const track = carousel.querySelector('.service-cards');
  const [prev, next] = carousel.querySelectorAll('.carousel-btn');
  const bar = carousel.querySelector('.carousel-progress span');
  const reduce = window.matchMedia('(prefers-reduced-motion: reduce)').matches;

  const step = () => {
    const card = track.querySelector('.service-card');
    const gap = parseFloat(getComputedStyle(track).columnGap) || 0;
    return card ? card.getBoundingClientRect().width + gap : track.clientWidth;
  };

  const update = () => {
    const max = track.scrollWidth - track.clientWidth;
    const pos = max > 0 ? track.scrollLeft / max : 1;
    prev.disabled = track.scrollLeft <= 2;
    next.disabled = track.scrollLeft >= max - 2;
    // The indicator is as wide as the visible share of the row and slides along with it.
    const visible = Math.min(track.clientWidth / track.scrollWidth, 1) * 100;
    bar.style.width = `${visible}%`;
    bar.style.marginLeft = `${pos * (100 - visible)}%`;
  };

  [prev, next].forEach((btn) => btn.addEventListener('click', () => {
    track.scrollBy({ left: Number(btn.dataset.dir) * step(), behavior: reduce ? 'auto' : 'smooth' });
  }));
  track.addEventListener('scroll', update, { passive: true });
  window.addEventListener('resize', update);
  update();
});
</script>

        <h2>What is lipedema?</h2>
        <p>Lipedema is a chronic condition in which fat builds up in an abnormal way, usually in the legs and sometimes the arms. It affects mostly women and often starts or gets worse around hormonal changes such as puberty, pregnancy or menopause.</p>
        <p>Lipedema is often mistaken for ordinary weight gain or for lymphedema. Many people live with it for years before getting a diagnosis, and the fat it causes usually doesn’t respond to diet and exercise alone.</p>

        <h2>Common signs</h2>
        <ul>
          <li>Fat build-up on both legs, or both arms, that looks out of proportion with the rest of the body</li>
          <li>Feet and hands that are not affected, sometimes with a “cuff” of tissue at the ankles or wrists</li>
          <li>Legs that feel painful, tender or heavy</li>
          <li>Bruising easily</li>
          <li>Little change in the affected areas despite weight loss</li>

        <h2>What is lymphedema?</h2>
        <p>Lymphedema is swelling caused by a build-up of lymph fluid when the lymphatic system can’t drain it properly. It most often affects an arm or a leg.</p>
        <p>Some people are born with differences in their lymphatic system. More often, lymphedema develops after the lymph nodes or vessels are damaged, for example by cancer surgery, radiation, infection or injury.</p>

        <h2>Common signs</h2>
        <ul>
          <li>Swelling in part or all of an arm or leg, including fingers or toes</li>
          <li>A feeling of heaviness or tightness</li>
          <li>Clothing, rings or shoes that feel tighter than usual</li>
          <li>Less flexibility in the affected limb</li>
          <li>Skin that becomes thicker or harder over time</li>
        </ul>
        <p class="callout"><strong>Get urgent care</strong> for sudden swelling in one leg or arm, especially with pain, warmth or redness, or with shortness of breath. These can be signs of a blood clot or infection.</p>
